IMPORTANT CONFIGURATION

DATABASE CREDENTIALS (Edit codelens/settings.py):

For SQL Server:
    DATABASES = {
        'default': {
            'ENGINE': 'sql_server.pyodbc',
            'NAME': 'CodeLensDB',
            'USER': 'sa',                    # ← CHANGE THIS
            'PASSWORD': 'YourPassword',      # ← CHANGE THIS
            'HOST': 'localhost',
            'PORT': 1433,
            'OPTIONS': {
                'driver': 'ODBC Driver 17 for SQL Server',
            },
        }
    }

For SQLite (Testing):
    DATABASES = {
        'default': {
            'ENGINE': 'django.db.backends.sqlite3',
            'NAME': BASE_DIR / 'db.sqlite3',
        }
    }

1. Install ODBC Driver 17 for SQL Server first
2. Create CodeLensDB database in SQL Server Management Studio
3. Update USER and PASSWORD in settings.py
4. Run: python manage.py migrate

WHAT HAPPENS WHEN USER...
═══════════════════════════════════════════════════════════════════════════════

...SIGNS UP
1. User enters email, username, password
2. Data validated and password hashed
3. User created in auth_user table
4. UserProfile created
5. User automatically logged in
6. Redirected to home page

...LOGS IN
1. Django authenticates email/password
2. Session created and stored
3. User redirected to home page
4. Username shown in navbar

...ANALYZES CODE
1. Python code submitted via AJAX
2. Django receives code
3. AST parsing analyzes code
4. Results stored in CodeAnalysis table
5. History entry created
6. User redirected to results page
7. Results displayed with tabs

...VIEWS HISTORY
1. Django queries all user's analyses
2. Applies search/filter if provided
3. Returns paginated results (10 per page)
4. User can star, delete, or view each
