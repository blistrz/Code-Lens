Static Analysis Driven by AI & Heuristics

CodeLens combines traditional deterministic compiler analysis with modern large language models to construct a comprehensive evaluation of Python software architecture, OOP patterns, and anti-patterns.

The 4 Pillars of CodeLens Engine

Deterministic AST Compilation

The code editor performs live lexical syntax evaluation by compiling Python source code directly into an Abstract Syntax Tree (AST). This isolates syntactic errors, unclosed scopes, and indentation failures before processing starts.

ast module Syntax Validation

OOP Concept Inspector

A custom AST NodeVisitor inspects class architectures. It maps class inheritances, method signatures, visibility types (public, protected, private), and object interfaces to build a full model of the OOP configuration.

Inheritance Trees Method Mapping Polymorphism

ML & Heuristic Smell Detection

Integrates a custom Random Forest machine learning classifier to predict software defects based on code features, complemented by heuristics identifying God Functions, Spaghetti Complexity, and Magic Numbers.

Random Forest ML Defect Predictor AST Heuristics

AI Refactoring Pipeline

Code containing design anomalies is parsed and passed to the Hugging Face AI pipeline running Qwen2.5-Coder. The AI system generates optimal refactoring choices, demonstrating how to align source code with clean SOLID design rules.

Qwen2.5-Coder-32B SOLID Design Hugging Face API

Code Analysis Lifecycle

Follow the path your Python scripts travel as they are compiled and parsed from plain text to beautiful dashboards:

1

Source Submission

Input raw Python code via paste, file upload, or importing public/private GitHub and Gist URLs.

2

AST Compilation

Build the abstract syntax trees, identifying structural tokens, syntax metrics, and function footprints.

3

ML Defect & Smell Prediction

Extract OOP structures and complexity heuristics via AST, then feed quantitative metrics (such as class and function counts) to a balanced Random Forest Classifier to predict defect probabilities.

4

Generative AI Fix

Query Hugging Face APIs asynchronously to build clean-code alternatives and explanations.

5

Interactive Insights

Render interactive glassmorphic charts, drill down into code details, and review starred history.
