💡 About
What is CodeLens?
CodeLens is an intelligent web platform that automatically reads your Python code and delivers a professional-grade analysis — instantly.

Whether you're a student, developer, or educator, CodeLens saves hours of manual review with zero configuration needed.
🔴 The Problem
Syntax errors that crash the program
Code smells — magic numbers, long functions
OOP violations — missing classes, bad design
Hard-to-read logic that breaks under change
"If code works but looks messy or confusing — refactor it."
— The Golden Rule of Clean Code
