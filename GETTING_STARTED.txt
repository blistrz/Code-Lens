📦 INSTALLATION STEPS
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Install Python Dependencies
-----------------------------------

Open Command Prompt and go to the project directory:

cd c:\Users\butta\OneDrive\Desktop\new bpee\django_project\

Create virtual environment:
python -m venv venv

Activate virtual environment:
venv\Scripts\activate

Install required packages:
pip install -r requirements.txt

This will install:
- Django 4.2.8
- pyodbc (SQL Server connection)
- django-pyodbc-azure (Django + SQL Server integration)
- python-decouple (Environment variables)
- requests (HTTP library)


STEP 2: Install ODBC Driver (For SQL Server)
--------------------------------------------

Download and install "ODBC Driver 17 for SQL Server":
https://learn.microsoft.com/en-us/sql/connect/odbc/download-odbc-driver-for-sql-server

Choose the version matching your Windows (x86 or x64)

This driver allows Python to connect to SQL Server database.


STEP 3: Configure Database Connection
-------------------------------------

Edit the file: codelens/settings.py (around line 70)

Find the DATABASES section and update it:

DATABASES = {
    'default': {
        'ENGINE': 'sql_server.pyodbc',
        'NAME': 'CodeLensDB',              # Database name
        'USER': 'sa',                       # Your SQL Server username
        'PASSWORD': 'YourPassword123',      # Your SQL Server password
        'HOST': '127.0.0.1',                # Server address
        'PORT': 1433,                       # Default SQL Server port
        'OPTIONS': {
            'driver': 'ODBC Driver 17 for SQL Server',
        },
    }
}

Replace:
- USER: Your SQL Server login username (usually 'sa')
- PASSWORD: Your SQL Server password
- HOST: Your server address (localhost for local)


ALTERNATIVE: Use SQLite (For Testing)
=====================================

If you don't have SQL Server, use SQLite:

Uncomment this section in settings.py (around line 80):

DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.sqlite3',
        'NAME': BASE_DIR / 'db.sqlite3',
    }
}

SQLite creates a local file database (no server needed).


STEP 4: Create Database in SQL Server
-------------------------------------

1. Open SQL Server Management Studio
2. Right-click "Databases" → New Database
3. Name: CodeLensDB
4. Click OK

The Django migrations will create the tables automatically.


STEP 5: Run Django Migrations
-----------------------------

In Command Prompt (with venv activated):

python manage.py migrate

This creates all necessary database tables for:
- Users
- User Profiles
- Code Analysis Records
- Analysis History


STEP 6: Create Admin User
------------------------

python manage.py createsuperuser

Enter:
- Username: admin
- Email: admin@localhost.com
- Password: (choose a strong password)
- Repeat Password: (confirm)


STEP 7: Collect Static Files
----------------------------

python manage.py collectstatic --noinput

This gathers all CSS and JavaScript files in the correct location.


STEP 8: Start the Development Server
-----------------------------------

python manage.py runserver

You should see:
Starting development server at http://127.0.0.1:8000/

The server is now running!

🗄️ DATABASE STRUCTURE
═══════════════════════════════════════════════════════════════════════════════

The application uses these database tables:

1. auth_user (Django built-in)
   - Stores user login credentials
   - Fields: id, username, email, password, is_active, etc.

2. analyzer_userprofile
   - Extended user information
   - Fields: user_id, total_analyses, created_at, updated_at

3. analyzer_codeanalysis
   - Stores code analysis records
   - Fields: user_id, code_input, errors_detected, oop_concepts,
             code_smells, refactoring_suggestions, status, etc.

4. analyzer_analysishistory
   - Tracks analysis history with metadata
   - Fields: user_id, analysis_id, title, tags, is_starred,
             is_deleted, created_at, viewed_at

All tables are automatically created by Django migrations.

💾 DATABASE QUERIES (Behind the Scenes)
═══════════════════════════════════════════════════════════════════════════════

When you analyze code:
1. Django saves your code to analyzer_codeanalysis table
2. Performs AST analysis
3. Saves errors, OOP concepts, code smells
4. Creates entry in analyzer_analysishistory
5. Updates user_profile with total_analyses count

When you view history:
1. Django queries analyzer_analysishistory for your user_id
2. Joins with analyzer_codeanalysis for full data
3. Returns paginated results (10 per page)

When you search:
1. Django filters history by title or tags
2. Returns matching analyses

🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

PROBLEM: "ModuleNotFoundError: No module named 'sql_server'"
SOLUTION: pip install django-pyodbc-azure

PROBLEM: "ODBC Driver not found"
SOLUTION: Install ODBC Driver 17 for SQL Server from Microsoft

PROBLEM: "Database CodeLensDB does not exist"
SOLUTION: Create it in SQL Server Management Studio first

PROBLEM: "Login always fails"
SOLUTION: 
- Check database is connected: python manage.py shell
- Verify user exists: User.objects.all()
- Create superuser: python manage.py createsuperuser

PROBLEM: "Static files (CSS/JS) not loading"
SOLUTION: python manage.py collectstatic --noinput

PROBLEM: "Connection refused at 127.0.0.1:1433"
SOLUTION: 
- Verify SQL Server is running
- Check HOST and PORT in settings.py
- Try: telnet localhost 1433

PROBLEM: "No such table: analyzer_codeanalysis"
SOLUTION: Run migrations: python manage.py migrate
