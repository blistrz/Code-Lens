# ===== USAGE WORKFLOW =====

1. User visits home page (/)
2. User clicks "Analyze Code" without login -> prompted to login
3. User signs up (/signup/) with email and password
4. User logs in (/login/)
5. User enters Python code in editor
6. User clicks "Analyze Code" button
7. AJAX sends code to /analyze/ endpoint
8. Backend performs code analysis using AST
9. Results saved to database
10. User redirected to /functionalities/?id=<analysis_id>
11. Results displayed in tabbed interface
12. User can view history (/history/)
13. User can search and filter analyses
14. User can star/delete analyses
15. User can click to view any previous analysis

# ===== TROUBLESHOOTING =====

1. "No module named 'sql_server'" 
   - Install: pip install django-pyodbc-azure

2. "ODBC Driver not found"
   - Install Microsoft ODBC Driver 17 for SQL Server

3. "Database does not exist"
   - Create database in SQL Server Management Studio first

4. "Static files not found"
   - Run: python manage.py collectstatic --noinput

5. "Login always fails"
   - Ensure superuser created: python manage.py createsuperuser
   - Check database connection
