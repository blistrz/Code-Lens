   Edit: codelens/settings.py (around line 70)
   Update:
     - USER: your_username (usually 'sa')
     - PASSWORD: your_password

☐ STEP 4: Open Terminal/Command Prompt
   cd c:\Users\butta\OneDrive\Desktop\new bpee\django_project\

☐ STEP 5: Install Dependencies
   Option A (Quick - Windows):
     quickstart.bat
   
   Option B (Manual):
     python -m venv venv
     venv\Scripts\activate
     pip install -r requirements.txt

☐ STEP 6: Run Database Setup
   python manage.py migrate

☐ STEP 7: Create Admin User

   python manage.py collectstatic --noinput

☐ STEP 9: Start the Server
   python manage.py runserver

⚙️ IMPORTANT CONFIGURATION

DATABASE SETUP (MUST DO):

1. Open: codelens/settings.py

2. Find this section (around line 70):
   
   DATABASES = {
       'default': {
           'ENGINE': 'sql_server.pyodbc',
           'NAME': 'CodeLensDB',
           'USER': 'sa',                    # ← CHANGE THIS
           'PASSWORD': 'YourPassword123',   # ← CHANGE THIS
           'HOST': 'localhost',
           'PORT': 1433,
           'OPTIONS': {
               'driver': 'ODBC Driver 17 for SQL Server',
           },
       }
    }

3. Replace:
   - USER: Your SQL Server username (usually 'sa')
   - PASSWORD: Your SQL Server password
   - HOST: Your server address (localhost for local)

4. Save the file

═══════════════════════════════════════════════════════════════════════════════
📞 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

PROBLEM: "ODBC Driver 17 for SQL Server not found"
SOLUTION: Download and install from Microsoft official website

PROBLEM: "Database CodeLensDB does not exist"
SOLUTION: Create it in SQL Server Management Studio first

PROBLEM: "Connection refused to SQL Server"
SOLUTION: 
  - Verify SQL Server is running
  - Check HOST, USER, PASSWORD in settings.py
  - Try: telnet localhost 1433

PROBLEM: "No such table: analyzer_codeanalysis"
SOLUTION: Run migrations
  python manage.py migrate

PROBLEM: "Static files not loading (CSS/JS)"
SOLUTION: 
  python manage.py collectstatic --noinput

PROBLEM: "ModuleNotFoundError: sql_server"
SOLUTION: 
  pip install django-pyodbc-azure

For more help, read: GETTING_STARTED.txt

🎯 WHAT HAPPENS WHEN USER CLICKS "ANALYZE CODE"
═══════════════════════════════════════════════════════════════════════════════

1. JavaScript collects code from textarea
2. AJAX sends POST request to /analyze/
3. Django receives request
4. Code is parsed using Python AST module
5. Analysis results generated (errors, OOP, smells)
6. Results saved to database
7. History entry created
8. JSON response sent back
9. User redirected to results page
10. Results displayed in tabbed interface
